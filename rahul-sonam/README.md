# राहुल एवं सोनम — शुभ विवाह आमंत्रण

React + Vite + Tailwind based wedding invitation.

## चलाने के लिए

```bash
npm install
npm run dev
```

फिर Vite का दिया हुआ local URL browser में खोलें।

## बदले गए विवरण

- वर: राहुल सिंह
- वर के पिता: श्री सचिन्द्र सिंह
- वर की माता: श्रीमती प्रमिला देवी
- वधू: सोनम सिंह
- वधू के पिता: श्री विवेक नाथ सिंह
- वधू की माता: श्रीमती संगीता देवी
- तिलक: २१ नवम्बर २०२६, शनिवार
- मेहंदी: २२ नवम्बर २०२६, रविवार
- हल्दी मटकोर: २३ नवम्बर २०२६, सोमवार
- विवाह: २४ नवम्बर २०२६, मंगलवार
